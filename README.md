# COTI Privacy DeFi Dashboard

Privacy-preserving DeFi dashboard built on COTI V2 — leveraging confidential smart contracts for private portfolio tracking, token transfers, and yield monitoring.

## Why COTI?
COTI V2 is the fastest privacy layer in Web3, offering confidential smart contracts with Privacy-on-Demand. Built for the COTI Builders Program.

## Features
- Private portfolio tracking (encrypted balances)
- Confidential token transfers
- Privacy-preserving yield aggregation
- Dashboard with real-time analytics

## Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Contracts:** Solidity (COTI V2 EVM-compatible)
- **Privacy:** COTI's native confidential computation
